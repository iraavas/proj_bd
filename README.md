# Автоматизированная система записи к врачу

Учебный проект по курсу «Распределённые и облачные базы данных».

Реализует распределённую архитектуру с тремя специализированными базами данных:

- **PostgreSQL** — для хранения транзакционных данных (клиенты, записи на приём)  
- **MongoDB** — для хранения документов и метаинформации (заключения врачей, сканы анализов)  
- **Redis** — для работы со справочниками (услуги, врачи, клиники, роли)

## Поддерживаемые сценарии

### Клиент
- Регистрация и вход  
- Просмотр записей на приём  
- Создание новой записи  
- Просмотр документов по прошедшим визитам  

### Врач
- Просмотр расписания приёмов  
- Добавление заключения после визита  

### Администратор
- Управление справочниками (услуги, врачи, клиники)

## Соответствие техническому заданию

Проект полностью реализует требования из файла «Проект.pdf»:

- Распределённая архитектура из трёх специализированных баз данных  
- Выбор СУБД по типу данных:  
  - **PostgreSQL** — реляционные транзакции  
  - **MongoDB** — неструктурированные документы  
  - **Redis** — высокоскоростные справочники (key-value)  
- Поддержка всех CRUD-сценариев из технического задания  
- Гарантия согласованности данных при создании записи и завершении приёма  
- Запрет на удаление данных (только архивация или изменение статуса на «завершён»)
